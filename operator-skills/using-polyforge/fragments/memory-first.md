## Memory-First Principle

**All memory lives in AIHub** - recall with `pf recall`, write with
`pf remember`. The harness's local `.md` memory is deprecated here: do not
read or write local memory files.

Before every substantive action: `pf recall <query> --limit 5`, and show the
hits under `Relevant history (not binding)` as
`· [<type>] <title or first line>`.
