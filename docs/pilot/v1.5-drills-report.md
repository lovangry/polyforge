## Findings the drills produced (fixed same day)

1. **Error swallowing in gitops** (`git init`/`git symbolic-ref` wrappers
   printed stdout — empty on failure — instead of the stderr-carrying

2. **Relative -data-dir footgun**: GIT_DIR resolved under the capsule
   worktree ('not a git repository'). daemon.New now absolutizes DataDir
   and WorkspaceRoot; the clone→local-init fallback logs the clone error
   it fell back from. Fixed 0ecc9e4.
3. **Stale executor skill**: pf-execute/SKILL.md still taught the deleted
   PF_INSTANCE_ID/attempt_id faces — a real-pi agent would fail-closed
