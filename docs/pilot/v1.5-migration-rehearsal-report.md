## Cutover-scale gaps the rehearsal surfaced (all fixed same-day, main @ 02594b0 + 35b4350)

1. **seq semantics mismatch** (owner ruling a): legacy numbers per-project,
   v1.5 numbered globally — every cross-project #N would collide. Fixed:
   per-project seq across create/import/lookup + an idempotent legacy-DB
   renumber migration.
2. **goal cap**: v1.5 caps goals at 500 BYTES (CJK-heavy legacy goals far
   exceed); import now truncates rune-aligned and preserves the original
   in attrs.legacy_goal; the re-run verifier mirrors the normalization.
3. **memories at scale**: rebuild-index exceeded the 60s client timeout
   at 3760 records — now scoped+batched FTS with `--rebuild-timeout`;
   verification probes were 3-char semantic probes useless without an
   embedding provider — now exact content-match probes; count
   reconciliation now project-scoped.
4. **list page cap**: the WI list endpoint hardcoded LIMIT 500 — silently
   undercounted a 678-wrapped project in verification. Now `?limit=`
   (clamped 50k). This is also a production-readiness fix: the legacy
   library carries projects with 1000+ records.
5. **import idempotency reporting**: pass-2 runs now end with a clean
   summary and exit 0 instead of a raw CORE-409 tail line.

## Registered for the real cutover decision (NOT done in this rehearsal)

1. **Drain backlog**: 387 non-terminal WIs (queued 313, paused 66,
   running 8) cannot import as terminal records — they must be drained,
   finished, or explicitly canceled before the switch.
2. **Archived memories** (2155) excluded by scope — the owner must rule
   whether any historical value justifies carrying them.
3. **agent_events history** (12 monthly partitions) not carried — the
   v1.5 event model is capsule-side; decide whether an archive dump is
   wanted for audit.
4. **Legacy steps/attempt lineages** not carried (v1.5 has no server-side
   step ledger by design); terminal records carry only attrs-preserved
   legacy metadata.
5. The rehearsal ran WITHOUT an embedding provider on the scratch
   target (lexical FTS only). Production v1.5 memory recall quality
   should be re-measured with the embedding provider configured.
6. Actual cutover requires: a fresh delta extract at switch time, the
   backup/rollback procedure, and the owner's explicit go — none of
   which this rehearsal performs.
